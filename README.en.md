# SlipAtlas

Turns scattered WeChat articles, videos and long-form pieces into searchable slips.

The **input** piece of Frost &middot; Armil &middot; Slip: FrostSword executes, ArmilGrid aims, SlipAtlas just reads inward.

中文主文档见 [README.md](README.md)。

## What it does

1. **Fetch** — given a link, pull the body text (or subtitles) into a local Markdown file
2. **Summarize** — a Chinese summary stating only what the author claims and on what grounds
3. **Tag** — 3 to 5 tags, drawn from words that actually appear in the text
4. **Store** — normalized URL plus a content hash, so the same piece never lands twice
5. **Query** — cross-article retrieval, every answer pointing back to the source

## What it does not do

- No career advice (that is ArmilGrid's job)
- No conclusions on your behalf, only what the text says and whether it is worth continuing
- No invented bodies when a fetch fails

## Install

```powershell
git clone https://github.com/Duckweed-yhb/SlipAtlas.git
Copy-Item -Recurse SlipAtlas "$env:USERPROFILE\.claude\skills\slipatlas"
Copy-Item SlipAtlas\config.example.toml "$env:USERPROFILE\.claude\skills\slipatlas\config.toml"
```

Copy the whole repository, not only `SKILL.md` — `tools/` and `schema.md` are used too.
Set the vault path in `config.toml`; the default is `E:/future/yhb/07-阅读与藏书/Lifetime-Archive`.

## Commands

| Command | Purpose |
| --- | --- |
| `/slip intake <url>` | Fetch one piece, store it, tag it |
| `/slip intake <url> --text-file body.md` | Paste the body when fetching fails |
| `/slip digest` | Work through the `status: inbox` queue |
| `/slip ask <question>` | Cross-article retrieval |
| `/slip list` | See how much is still unprocessed |

## Where data lands

```
Lifetime-Archive/
└─ sources/
   ├─ 2026/
   │  └─ 2026-11-19-<slug>.md     # one file per piece, fields in schema.md
   └─ index.md                    # generated by tools/index.py, do not edit
```

Books and screen titles stay in `Lifetime-Archive_总表.xlsx` (the existing 14-column sheet, untouched); articles and videos go to `sources/`.
